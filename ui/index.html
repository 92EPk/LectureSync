Set up LectureSync

Three quick steps. Everything runs in Google's cloud — not on your internet.

  1. 1Step 1Telegram keys
  3. 2Step 2Cloud engine
  5. 3Step 3Sign in

  1. Add your Telegram keys

    A one-time API ID and API Hash from your own Telegram account. They're encrypted and never leave this PC.

    Need help getting API keys?
    1. Open my.telegram.org and log in with your phone number.
    2. Click API development tools.
    3. Type any app title (e.g. LectureSync) and short name, then press Create application.
    4. Copy App api_id and App api_hash into LectureSync. You only do this once.

    ✓ Keys saved and encrypted

  2. Start your cloud engine

    A free Google Colab engine does the heavy lifting for you.

    1Runin the opened page
    2Allow DriveGoogle asks once
    3Connectpress the green button

    Code copied. Paste it in the new notebook, run it, then copy the LECTURE_SYNC_URL line — the app connects by itself.
    Connect with a link · Use my own notebook

  3. Sign in to Telegram

    Scan once with your phone. You'll stay signed in.

    Press the button to show the code
    Fastest and most reliable way

    On your phone open Telegram → Settings → Devices → Link Desktop Device, then scan this code.

    Sign in with phone code instead

Send to Telegram

Tick files or folders in Google Drive, then press Send to Telegram.

Everything travels from Colab straight to Telegram — your own internet isn't used.

Folders can go as one ZIP or file by file. Anything bigger than Telegram's limit (2 GB, or 4 GB with Premium) is split into parts only after you agree.

Import from a link

Public or "anyone with the link" shares only: SharePoint / OneDrive, Google Drive, Dropbox, MediaFire, YouTube (videos & playlists), Telegram messages (t.me/…) and direct file links.

          LectureSync

          Student initiative · FGSSR, Cairo University

          Pulls lecture recordings from Telegram, extracts them on Google Colab and puts them straight into your cloud (Google Drive or OneDrive) — without using your home internet.

          A free student initiative built by a Computer Science Diploma student at the Faculty of Graduate Studies for Statistical Research (FGSSR), Cairo University, to help fellow students move their lectures easily.
