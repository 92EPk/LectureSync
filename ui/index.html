Set up LectureSync

Three quick steps. Everything runs in Google's cloud — not on your internet.

  3. 2Step 2Cloud engine

  1. 🔑

    Add your Telegram keys

    A one-time API ID and API Hash from your own Telegram account. They're encrypted and never leave this PC.

    ✓ Keys saved and encrypted

  2. ☁

    Start your cloud engine

    A free Google Colab engine does the heavy lifting for you.

    2Allow DriveGoogle asks once

    Code copied. Paste it in the new notebook, run it, then copy the LECTURE_SYNC_URL line — the app connects by itself.
    Connect with a link · Use my own notebook
  3. ✈

    Sign in to Telegram

    Scan once with your phone. You'll stay signed in.

    Press the button to show the code
    Fastest and most reliable way

    On your phone open Telegram → Settings → Devices → Link Desktop Device, then scan this code.

    Sign in with phone code instead

Send to Telegram

Tick files or folders in Google Drive, then press Send to Telegram.

Everything travels from Colab straight to Telegram — your own internet isn't used.

Folders can go as one ZIP or file by file. Anything bigger than Telegram's limit (2 GB, or 4 GB with Premium) is split into parts only after you agree.

Import from a link

Public or "anyone with the link" shares only: SharePoint / OneDrive, Google Drive, Dropbox, MediaFire, YouTube (videos & playlists) and direct file links.

          Switches save instantly. Telegram keys need the Save button.

          Keep the computer awakeStops sleep only while transfers run, then lets it sleep normally.
          Try again automaticallyIf the connection drops, the transfer restarts by itself before it is marked Failed.
          Sound when finishedA soft chime when a transfer is done.
          Desktop notificationA pop-up from your system when a transfer is done.
          Minimize to trayThe minimize button hides the app next to the clock instead of the taskbar.
