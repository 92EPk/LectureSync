Let's get you set up

Three steps. You only do step 1 once; after that it's one click each time.

  1. 1

    Your Telegram keys

    Every user uses their own Telegram account. Get your API ID and API Hash from Telegram's developer page (log in with your phone → API development tools → create any app).

    Saved on this PC (encrypted).

  2. 2

    Start the Colab engine

    The ready LectureSync notebook opens in your own browser (Chrome, Edge…), where you're already signed in to Google. Press Run ▶, allow Google Drive, then click the green Connect to LectureSync button. No copying, no pasting.

    A new Colab notebook opened in your browser and the code is copied. Click inside the cell, press Ctrl+V then Ctrl+Enter and allow Drive. When the line LECTURE_SYNC_URL=… appears, select it and press Ctrl+C. The app connects by itself.
  3. 3

    Sign in to Telegram

    Connects automatically once Colab is running. The first time only, Telegram sends you a login code.

    Press the button to show the code
    Fastest and most reliable way

    On your phone open Telegram → Settings → Devices → Link Desktop Device, then scan this code.

    Sign in with phone code instead
